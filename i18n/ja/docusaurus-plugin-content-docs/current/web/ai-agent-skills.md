# AI エージェント スキル

Reveal SDK には、Claude Code、GitHub Copilot、Cursor などの AI コーディング アシスタントに Reveal を使用した開発方法を教える[エージェント スキル](https://agentskills.io) が付属しています。スキルは、指示、リファレンス ページ、スターター コードをまとめたフォルダーで、アシスタントはリクエストに必要な場合にのみそれを読み込みます。スキルをインストールすると、アシスタントは Web を検索して API を推測するのではなく、厳選された Reveal のガイダンスに基づいて作業します。

スキルは、Reveal.Sdk GitHub リポジトリの [`skills/`](https://github.com/RevealBi/Reveal.Sdk/tree/main/skills) フォルダーにあります。

## reveal-embed スキル

`reveal-embed` は、独自のアプリケーションに Reveal ダッシュボードを埋め込む作業を支援します。次の内容を扱います。

- **サーバーのセットアップ**: ASP.NET Core、Node.js (Express、NestJS、CommonJS、ES モジュール)、Java (Spring Boot、Jakarta EE 9 コンテナー)
- **クライアントのセットアップ**: プレーンな HTML/JavaScript、Angular、React、Vue、Web コンポーネント ラッパー
- **データ ソース**: SQL Server、PostgreSQL、Snowflake、REST、Excel/CSV、インメモリ データなど。接続の詳細はサーバー上に保持されます。
- **ユーザー コンテキストとセキュリティ**: サインイン中のユーザーをサーバーのサンプルに渡す方法、マルチテナンシー、ユーザーごとの資格情報。
- **ダッシュボード**: ダッシュボードの読み込み、保存、作成、およびファイル システム外への保存。
- **テーマ設定とデータ エクスポート**
- **トラブルシューティング**: 空白またはスタイルが適用されないビュー、CORS エラー、空のウィジェット、エクスポートの失敗など、最も一般的なセットアップの問題。

また、アシスタントがアプリケーションに合わせて調整する、最小限の ASP.NET Core および Node.js プロジェクトも含まれています。

## スキルの使用

スキルを名前で呼び出す必要はありません。プロジェクト内の Reveal についてアシスタントに質問すると、アシスタントが自動的にスキルを読み込みます。次に例を示します。

- *「この ASP.NET Core アプリに Reveal ダッシュボードを追加し、それを表示する React ページも追加してください。」*
- *「接続文字列をブラウザーに公開せずに、Reveal を SQL Server データベースに接続してください。」*
- *「各テナントが Reveal ダッシュボードで自分の注文のみを表示できるようにしてください。」*
- *「RevealView が空白で、コンソールに CORS エラーが表示されます。何が問題でしょうか?」*

アシスタントはまず、サーバーとクライアントのスタックを確認し、1 つのダッシュボードが表示される状態にします。その後、データ、セキュリティ、仕上げの順に追加します。最後にチェックリストで確認します。ダッシュボードがブラウザーで表示されること、資格情報がサーバー上に保持されること、CORS が制限されていること、ライセンス キーがソース管理に含まれていないことを確認します。

:::tip

スキルは、依存性の注入、構成、コード スタイルなど、プロジェクトの既存の規約に従います。アシスタントがプロジェクト ファイルを読み取れるように、アプリケーションのルート フォルダーからアシスタントを実行してください。

:::

## スキルの効果

さまざまなアプリで、スキルを使用した場合と使用しない場合の両方で、同じ埋め込みタスクを実行しました。各実行は、ブラウザー チェック、セキュリティ プローブ、静的コード チェック、LLM 判定など、複数の指標で評価しました。

| --- | スキルなし | スキルあり |
| --- | --- | --- |
| **品質** | | |
| 判定スコア | 21/30 (70%) | **28/30 (93%)** |
| **工数とコスト** | | |
| 実時間 | 72 分 | **36 分** |
| エージェントのターン数 | 439 | **275** |
| ツール呼び出し数 | 465 | **270** |
| 処理されたトークン (キャッシュ読み取りを含む) | 76.9M | **30.4M** |
| 生成されたトークン (思考を含む) | 281k | **150k** |
| API 換算コスト | $31.27 | **$13.71** |
| **Reveal に関する知識の入手元** | | |
| Web 検索とドキュメント取得 | 23 | **0** |
| 情報源 | help.revealbi.io、GitHub サンプル、検索結果 | スキルのリファレンス ページ |

このテストでは、スキルを使用したエージェントは、最も重要な点で正しい結果を出す頻度が高くなりました。作業は約半分の時間と半分未満のコストで完了し、Web 検索の代わりに厳選されたガイダンスを使用しました。

:::note

これらの数値は社内テストによるもので、説明のみを目的として掲載しています。保証やベンチマークではありません。結果は、AI モデルとそのバージョン、コーディング アシスタントとその設定、プロンプト、プロジェクトのスタックと既存のコード、現在のモデル料金によって異なります。また、AI エージェントは非決定的であるため、同じタスクでも実行ごとに結果が異なる場合があります。

:::
